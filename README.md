# Зоопарк — учебный проект на Go

Проект демонстрирует ООП-принципы (инкапсуляция, полиморфизм) на примере
зоопарка и разделён на 4 независимых пакета — по одному на участника команды.

## Структура проекта

```
zoo-project/
├── go.mod
├── cmd/
│   └── zoo/
│       └── main.go              ← точка входа, собирает всё вместе
├── internal/
│   ├── animal/                  ← Зона 1: модели животных
│   │   ├── animal.go            interface Animal + базовая структура
│   │   ├── cat.go               Cat (Кот)
│   │   ├── parrot.go            Parrot (Попугай)
│   │   └── guinea_pig.go        GuineaPig (Морская свинка)
│   ├── zoo/                     ← Зона 2: вольеры и зоопарк
│   │   ├── enclosure.go         Enclosure (вольер)
│   │   └── zoo.go               Zoo, ZooShow
│   ├── staff/                   ← Зона 3: персонал
│   │   ├── employee.go          interface Employee
│   │   ├── keeper.go            ZooKeeper (смотритель)
│   │   ├── vet.go               Veterinarian (ветеринар)
│   │   └── schedule.go          FeedingSchedule (расписание кормления)
│   └── storage/                 ← Зона 4: сохранение состояния
│       └── json_store.go        SaveToJSON / LoadFromJSON
└── .vscode/                     конфигурация редактора
```

## Зоны ответственности

### Зона 1 — `internal/animal`
Интерфейс `Animal` и три конкретных вида животных: `Cat`, `Parrot`,
`GuineaPig`. Каждый вид встраивает общую структуру `baseAnimal` и
переопределяет часть методов (например, `GetInfo()`), демонстрируя
полиморфизм. Поля приватные — доступ только через методы (инкапсуляция).

### Зона 2 — `internal/zoo`
`Enclosure` (вольер) с ограничением вместимости и `Zoo`, объединяющий
вольеры. Метод `ZooShow()` перебирает всех животных и вызывает их методы
`GetInfo()`/`MakeSound()`, не зная конкретного вида каждого животного.

### Зона 3 — `internal/staff`
Интерфейс `Employee`, которому соответствуют `ZooKeeper` (смотритель) и
`Veterinarian` (ветеринар). `FeedingSchedule` хранит список задач
кормления и выполняет их по времени.

### Зона 4 — `internal/storage`
Сохранение и загрузка состояния зоопарка в JSON-файл. Поскольку `Animal` —
интерфейс, а не структура, используются промежуточные DTO-структуры с
полем `type`, по которому при загрузке выбирается нужный конструктор.

## Как запустить

Требуется Go 1.21+.

```bash
# Запуск программы
go run ./cmd/zoo

# Проверка стиля кода
go vet ./...
gofmt -l .

# Сборка бинарника
go build -o bin/zoo ./cmd/zoo
./bin/zoo
```

В VS Code достаточно открыть папку проекта (нужно расширение
**Go** от команды golang.go — VS Code предложит установить его сам)
и нажать `F5` для запуска через отладчик.

После запуска в корне проекта появится файл `zoo_state.json` с сохранённым
состоянием зоопарка (он добавлен в `.gitignore`, чтобы не попадать в
репозиторий).
